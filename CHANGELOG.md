## 0.1.0 — 2026-09-12

Primera versión pública preparada de SEO Production Guard.

### Skill

- Paquete autocontenido con `SKILL.md`, licencia y referencias bajo demanda dentro de `seo-production-guard/`.
- Flujos diferenciados para auditoría, implementación, diagnóstico de previews e indexación.
- Guías de Astro y Next.js App Router para metadatos por ruta, canonicals, Open Graph, Twitter Cards, robots y sitemap.
- Reglas para distinguir dominio estable, preview y desarrollo sin publicar hosts inventados.
- JSON-LD con composición explícita y serialización protegida al insertarlo como HTML.
- Hreflang construido únicamente con traducciones publicadas y `llms.txt` tratado como recurso opcional.
- Recomendaciones y límites documentados sin promesas de ranking, indexación, rich results o previews infalibles.

### Repositorio

- README en español e inglés sin emojis.
- Portadas SVG propias y accesibles para ambos README.
- Presentación ampliada con navegación, badges, matriz de alcance, ejemplos y arquitectura del paquete.
- Casos de origen para Astro, Vercel y Cloudflare presentados como contexto histórico, sin certificación actual.
- Guías de contribución, reportes sensibles y publicación.
- Plantillas de GitHub para issues y pull requests.
- Pruebas de mantenimiento para paquete, enlaces, versión, canonicals, sitemap y escape de JSON-LD.

English summary: initial release of the self-contained SEO Production Guard skill, with scoped Astro and Next.js guidance, behavioral maintenance tests and repository governance.
