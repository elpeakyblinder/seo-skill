# Reportar un problema de seguridad

Si una instrucción, plantilla, enlace o archivo pudiera exponer secretos, publicar datos privados, ampliar permisos del agente o provocar acciones no autorizadas sobre un sistema real, escribe a [devcharlying@gmail.com](mailto:devcharlying@gmail.com?subject=Reporte%20de%20seguridad%20-%20SEO%20Production%20Guard).

Se aceptan reportes en español e inglés. Para errores de documentación sin información sensible utiliza las [issues](https://github.com/elpeakyblinder/seo-skill/issues/new/choose).

## No publiques

No incluyas en issues o PR credenciales, tokens de verificación, datos personales, URLs firmadas, configuraciones privadas, objetivos explotables o pruebas de concepto contra terceros. No necesitas demostrar un problema sobre producción ni acceder a sistemas ajenos. Esta política no autoriza pruebas sobre infraestructura del autor o de terceros.

No envíes secretos por correo. Si necesitas compartir material sensible, solicita primero un medio adecuado.

## Información útil

- Versión o commit y archivo o apartado afectado.
- Riesgo, alcance estimado y pasos mínimos con datos sintéticos.
- Agente, modelo, framework y configuración relevantes.
- Resultado observado, resultado esperado y corrección propuesta, si la conoces.
- Indicación de si el problema afecta solo las instrucciones o fue reproducido en una aplicación.

Si el hallazgo pertenece a un proyecto distinto que utilizó la skill, sigue también la política de ese proyecto. La existencia de esta skill no convierte al autor en responsable de administrar sistemas de terceros.

## Respuesta y versiones

El mantenimiento se realiza según disponibilidad, sin plazo garantizado ni programa de recompensas anunciado. El reporte se evaluará y podrá requerir contexto adicional. Coordina la divulgación de detalles sensibles mientras se revisa.

La revisión se centra en `main` y la versión publicada más reciente. No se promete soporte de ramas antiguas ni ausencia de fallos. Consulta [CHANGELOG.md](CHANGELOG.md) y las [releases](https://github.com/elpeakyblinder/seo-skill/releases).
